# Mini-Project Sample Images

This directory contains sample images for the mini-project lessons.

## Required Images

### plaque.jpg
- **Purpose**: License plate detection (Mini-Project 2)
- **Description**: Image of a vehicle with a visible license plate
- **Recommended specifications**:
  - Format: JPEG
  - Size: 640x480 or similar
  - Content: Car with yellow license plate clearly visible
  - Lighting: Good contrast between plate and background
  - Quality: Clear, not blurry

### MP3.gif
- **Purpose**: Line segmentation (Mini-Project 3)  
- **Description**: Document image with text lines to be segmented
- **Recommended specifications**:
  - Format: GIF (or can be converted to JPEG/PNG)
  - Size: 600x800 or similar
  - Content: Document with multiple lines of text
  - Quality: Clear text with some noise or uneven lighting
  - Background: May have slight variations in illumination

## Usage

These images are automatically loaded when users access the corresponding lesson pages:
- `/lessons/license-plate-detection` → loads plaque.jpg
- `/lessons/line-segmentation` → loads MP3.gif

The complete processing pipelines are pre-configured with optimal parameters for these specific images.

## Adding Your Own Images

Users can also upload their own images through the input node in each lesson to test the algorithms on different data.
